Форма редактирования данных физического лица

В этой форме предоставлена возможность редактирования личных данных о физическом лице.

Внимание! Перед созданием новой записи убедитесь, что его еще нет в справочнике!

Для этого отключите режим иерархического просмотра и начните вводить в списке фамилию имя отчество. Текущий элемент списка будет позиционироваться на физлице с совпадающими ФИО. Если найдено физлицо с аналогичными ФИО, проверьте дату его рождения.

Создавать новуюю запись можно только в том случае, если в справочнике нет записи, совпадающей по ФИО и дате рождения.

Данные, обязательные для указания при создании страхователя.

  • Фамилия Имя Отчество (полностью и правильно, без ошибок!)
    В качестве "Наименования" (отображаемого в списках) выбирать ПОЛНОЕ ФИО.
  • Дата рождения
  • Пол

Данные, обязательные для указания при создании сотрудника.

    В качестве "Наименования" (отображаемого в списках) выбирать ФИО КРАТКО: Фамилия И.О.
  • Дата рождения
  • Пол
  • Место рождения
  • Удостоверение личности
  • Гражданство
  • Контактная информация

    • Телефон мобильный рабочий
    • Телефон домашний
    • Телефон (как мимнимум одного) родителя или родственника
    • Адрес фактиеского проживания
  • Движение сотрудника по подразделениям
  • Пользователь
