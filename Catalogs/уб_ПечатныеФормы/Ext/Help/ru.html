Справочник "Печатные формы"

Данный справочник используется для настройки дополнительных печатных форм для документов.  Для документов можно создавать неограниченное количество дполонительных печатных форм. Каждый элемент этого справочника соответствует одной печатной форме. В справочнике хранится макет печатной формы, код осуществляющий вывод этого макета на печать и настройки принадлежности формы к документу.

  • Принадлежность - на этой закладке определяется к какому документу будет принадлежать данная печатная форма, а так же дополнительные параметры, определяющие доступность печатной формы.
    • Объект конфигурации - имя документа, в котором печатается данная форма.
    • Можно использовать (Проверено) - если НЕ помечено, то форма не будет отображаться в меню печати документов.
    • ПФ по умолчанию - будет выбрана по умолчанию среди прочих форм в подменю печати.
    • Универсальная ПФ - отображается в подменю печати всегда.
    • Параметры, используемые не во всех документах. Форма будет присутствовать в подменю печати только при соответсвующем значении атрибута документа: Поставщик, Организация-Агент, ПараметрПринадлежности.
    • Выгружать эту печатную форму при XML обмене - служебный атрибут. Используется для пометки ПФ к выгрузке при при использовании универсального обмена данными в формате XML.
  • Макет - макет является стандартным табличным документом используемым в платформе 1С Предприятие 8.0. Создавать макет можно как в режиме предприятия, так и в режиме конфигуратора. Для более подробного изучения принципов создания макет нужно воспользоваться книгой "1С:Предприятие 8.0. Конфигурирование и администрирование" глава "Табличный редактор".
  • Код - на этой закладке пишется код, который будет выводить на печать макет. Код пишется в соответствии с правилами внутреннего языка платформы. Для более подробного изучения синтаксиса следует изучить книги "1С:Предприятие 8.0. Описание встроенного языка". Ограничением данного кода является лишь невозможность создавать дополнительные процедуры и функции, т.е. вся логика печати должна быть описана в одном блоке.
    В коде используется структура Контекст, содержащая необходимые объекты, параметры, настройки. Например, для получения доступа к макету в коде необходимо использовать Контекст.Макет, а для получения доступа к свойствам объекта документ можно использовать Контекст.Объект.

Закладка "Параметры макета" 

Раскраска строк

Белый фон - бычный параметр, который присутствует в макете. Заполняется процессором печати стандартным образом, то есть на основании своего имени.

Желтый фон - параметр, который присутствует в макете, но имеет частный код заполнения. Процессор печати заполнит параметр, выполнив код заполнения (см. "Код заполнения параметра" ниже)..

Зеленый фон - в этой строке указан свободный код области. Признак свободного кода области - имя параметра = "=". Этот код будет выполнен в начале обработки данной области. 

Оранжевый фон - строка свободного кода области (имя параметра = "=") но в ней не указан собственно код.

Розовый фон - не указано имя параметра. Такое случается, когда в макете у ячейки тип заполнения "Параметр", но ячейка пуста. Или в случае заполнения типа "Шаблон" в шаблоне есть символы квадратных скобок, между которыми пусто или нет ничего, кроме пробелов.

Серый текст - указанная область или указанный параметр отстутствует в макете.

Колонки пиктограмм

Во втором столбце появляется картинка  в следующих случаях:

  • Указанная область отсутствует в макете
  • Параметр не найден в указанной области макета

У таких параметров значение реквизита НетВМакете = Истина и в процессоре печати они не обрабатываются.

В четвертой колонке "КЗ" появляется картинка тогда, когда у параметра есть частный код заполнения. При обработке печати параметр будет заполняться результатом выполнения этого кода (см. "Код заполнения параметра" ниже).

Режим отладки печатных форм

Включает вывод дополнительной информации и отработки дополнительных отладочных действий при печати форм из справочника.

  • вывод сообщений об ошибках при выполнении кода заполнения параметров
  • все места подстановки параметров в макете, которым в коде обработки не присваиваются значения, будут заполнены строкой ###########. Это позволяет визуально отследить проблемные места в шаблоне и коде.

Настрока управляет значением параметра сеанса уб_отладка_Печати.

Код заполнения параметра

Если заполнено поле "Код заполнения параметра", то параметр будет заполняться результатом выполнения этого кода. Обязательным является присвоение желаемого значения параметра переменной ЗначениеПараметра.

А именно, конструкция 

ЗначениеПараметра = ...;

 

Функции заполнения параметров шаблона ПФ

Наименование параметра шаблона в справочнике печатных форм может быть как именем свойства контейнера свойств, так и функцией. В первом случае параметр шаблона будет заполнен значением свойства контейнера, во втором – результатом выполнения функции.

Аргументы функций (если это не вложенные функциии) указываются строкой имени свойства или зарегистрированного значения аргумента без кавычек.

Система автоматически распознает, является ли указанное имя именем свойства или зарегистрированным значением аргумента (в основном – на основании структуры аргументов: из положения аргумента ясно, чем он должен являться).

Допускается вложение функций, то есть использование результата выполнения внутренней функции как аргумента внешней функции. Это справедливо только для аргументов, которые отмечены как «Имя свойства контейнера или вычисляемое значение»

Договор(<ВидЗначения>, <Контрагент>, <Организация-партнер>, <форматная строка даты>)

Возвращает атрибут договора между Контрагентом и Организацией, действующий на дату документа.

Аргументы

<ВидЗначения>

ПолноеНаименование|ПН|П – возвращает полное наименование договора (расширение, номер и дату, например: «поручения № 345 от 12.04.2010г.»)

Расширение|Р – возвращает расширение названия договора.

Номер|Н – возвращает номер договора.

Дата|Д – возвращает дату договора (если не указана, возвращает пустую строку)

<Контрагент>

Имя свойства контейнера типа ссылки из справочника Контрагенты

<Организация-партнер>

Организация, являющаяся партнером Контрагента (для позиционирования на нужном договоре)

<форматная строка даты>

(необязательный)

Форматная строка по правилам 1С без ДФ= и без внешних кавычек.

Допускаются мнемоники:

Кратко – как задано в свойстве Контекст.ДФ_Кратко (dd.MM.yy)

Полно – как задано в свойстве Контекст.ДФ_Полный (dd.MM.yyyy)

ПолныйГод – как задано в свойстве Контекст.ДФ_Полный_год ("dd.MM.yyyy'г.'")

ПолныйМесяцГод – как задано в свойстве Контекст.ДФ_Полный_месяц_год ("dd MMMM yyyy'г.'")

 

По умолчанию – ПолныйГод

 

ERR:

- если ВидЗначения указан неверно

- если не найден действующий на дату документа договор между указанными контрагентом и организацией.

- если не указано значение требуемого атрибута

ТекущаяДата()

ТДата()

Возвращает текущую дату-время.

Используется как аргумент функции ДФ()

Заполнитель(<арг>, <символ>, <количество>)

З(...)

Заполняет параметр строкой из символов <символ> повторенных <количество> раз в том случае, если значение аргумента, представленное строкой – пустая строка.

Аргументы

<арг>

Имя свойства контейнера или вычисляемое значение.

<символ>

(необязательный)

Символ, которым будет заполняться результат функции, если строковое представление <арг> - пустая строка.

По умолчанию – символ подчеркивания «_»

<количество>

(необязательный)

Количество повторений <символ>.

По умолчанию 20
