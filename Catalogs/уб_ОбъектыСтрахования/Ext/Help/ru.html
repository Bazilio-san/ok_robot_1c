Справочник "Объекты страхования"

            Справочник служит для хранения информации об объектах страхования.

            Он состоит из колонок: «Код», «Наименование» — наименование объекта страхования, «Тип объекта» — тип объекта страхования. Список объектов страхования можно упорядочить по коду или по наименованию, по возрастанию или по убыванию. Для этого нужно нажать на стрелку у заголовка колонки.  Для ввода нового объекта страхования используется диалог — форма элемента справочника.

            Форма содержит реквизиты «Наименование» — название объекта и «Тип объекта» — тип объекта страхования. Реквизит «Тип объекта» имеет реквизит справочника «Типы объектов страхования».

            Если в справочник «Объекты страхования» добавляется новый объект с видом расширения «Транспортное средство», то для данного объекта страхования следует ввести дополнительные свойства типа объекта. Реквизиты дополнительных свойств имеют реквизиты справочников, в которые вносится общая информация о транспортных средствах. Дополнительные свойства типа объекта это: «Регистрационный знак» — регистрационный знак транспортного средства, «Идентификационный номер (VIN)» — идентификационный номер, «Марка ТС» — марка транспортного средства, «Модель» — модель транспортного средства, «Тип ТС» —тип транспортного средства, «Категория ТС» — категория транспортного средства, «Год выпуска ТС» — год выпуска транспортного средства, «Двигатель №» — заводской номер двигателя, «Шасси (рама) №» — заводской номер шасси (рамы) ТС, «Кузов (коляска) №» — заводской номер коляски или кузова, «Цвет» — цвет кузова транспортного средства, «Мощность двигателя, л.с.» — мощность двигателя транспортного средства, «Разрешенная max масса, кг» — максимальная разрешенная масса транспортного средства, «Грузоподъемность, кг» — максимальный разрешенный вес груза, «Количество пассажирских мест» — количество пассажирских мест в транспортном средстве, «Противоугонная система» — название противоугонной системы.

            Реквизит «Тип объекта» имеет справа две кнопки в виде троеточия и в виде лупы. Если нужно получить список всех типов объектов, чтобы потом выбрать один из имеющихся типов, либо добавить новый тип объекта, то следует нажать на значок троеточие.Откроется экранная форма списка справочника «Типы объектов». Если тип объекта страхования уже выбран и нужно изменить наименование типа объекта или изменить вид расширения, то следует нажать на кнопку с изображением лупы.

            Реквизит «Марка ТС» является реквизитом справочника «Марки ТС». Реквизит «Модель» является реквизитом справочника «Модели транспортных средств». реквизит «Категория ТС» содержит категорию ТС. Категория ТС может быть «A», «B», «C», «D», «E», «Прицеп». Реквизит «Цвет» является реквизитом справочника «Цвета». Реквизит «Противоугонная система» является реквизитом справочника «Противоугонные системы».
