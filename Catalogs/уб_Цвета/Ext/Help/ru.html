Справочник "Цвета"

Данный справочник используется для хранения списка цветов. Данный список используется для определения цвета ТС в справочнике Модели ТС.

            Справочник указывает цвет покраски кузова транспортного средства и имеет список цветов. Чтобы добавить новый цвет, нужно его добавить с помощью стандартных приемов и дать новому цвету наименование.
