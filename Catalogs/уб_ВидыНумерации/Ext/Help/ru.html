Справочник «Нумерации»

            Экранная форма списка справочника содержит информацию о видах нумерации БСО.

Справочник содержит реквизит «Страховая компания», являющийся реквизитом справочника «Контрагенты» и табличную часть. Сначала следует выбрать Страховую компанию. Для этого следует нажать на троеточиеи из справочника «Контрагенты», группы «Сраховые компании» выбрать страховую компанию. Затем добавляем новый вид нумерации.

            Табличная часть экранной формы списка имеет колонки: «Наименование» — наименование вида нумерации и еще четыре другие колонки, которые отображают область применения нумерации. Новый вид нумерации БСО создается в диалоге — форме элемента справочника «Виды нумерации».

            Чтобы задать область применения нумерации следует установить флажки в соответствующих реквизитах. Если страховой полис оформляется и тут же оплачивается, то для этого нужен БСО с областью применения нумерации «Для обычных полисов». Если платежи по счетам поступают в одной строке, то должен быть БСО с областью применения «Без рассрочки». Если страхователь вносит платежи за полис несколькими платежами, то потребуется БСО с областью применения нумерации «С рассрочкой». Если клиент берет кредит при оформлении полиса, то нужно ввести БСО с областью применения нумерации «Для кредитных полисов». После того, как добавлен новый вид нумерации, нужно вписать название нового вида в реквизит «Наименование». В табличную часть формы элемента нужно внести виды БСО, на которые будет распространяться данный вид нумерации. Виды БСО должны определяться с таким типом учета БСО, для которого номер полиса будет браться из списка свободных.
