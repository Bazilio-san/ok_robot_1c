Справочник "Виды бланков строгой отчетности (БСО)"

 

            Справочник предназначен для хранения информации о видах БСО. Если страховая компания выпускает новый вид БСО, то его нужно вводить в этом справочнике. Вначале нужно выбрать страховую компанию. После выбора страховой компании будут показаны все виды БСО, принадлежащие данной СК. Чтобы ввести новый вид БСО следует сделать таблицу активной. Для этого нужно щелкнуть один раз левой кнопкой мыши в любое место табличной части. После того, как таблица сделалась активной, нужно добавить новый элемент. Для этого следует нажать клавишу “Insert” или “Ins” на клавиатуре компьютера или нажать на панели инструментов кнопку «Добавить».

Справочник имеет реквизит «Страховая компания», где выбирается элемент справочника «Контрагенты» и табличную часть, содержащую три колонки: «Наименование» — наименование вида БСО, «Тип» — тип бланка, «Тип учета БСО». Табличная часть является списком видов БСО.

  

 Ввод нового вида БСО

            Новый вид БСО создается в диалоге — форме элемента справочника.

 

В форме расположены реквизиты «Наименование» — наименование нового вида БСО, «Тип» — тип БСО, «Тип учета БСО» — тип учета БСО.

Если тип БСО не бланк полиса по ОСАГО, не бланк спецзнака по ОСАГО, то при вводе нового вида бланка строгой отчетности,  тип учета БСО может быть одним из предложенных:

Есть номер БСО (номерной учет)

Нет номера БСО (количественный учет)

Нет номера БСО, колич. учет не ведется. Учет после оформления

Если тип учета БСО имеет номерной учет, то номер полиса может присутствовать или отсутствовать (стикеры, карточки). Номер полиса может соответствовать номеру БСО, может быть выбран из списка свободных или может заполняться вручную.

Если тип учета БСО имеет количественный учет, то номер полиса может отсутствовать или будет иметь номер, заполняемый вручную. Если страховая компания предоставляет определенный диапазон номеров БСО, то из данного списка номеров необходимо выбрать свободный номер для заполняемого полиса.

Если отсутствует номер БСО и не ведется количественный учет, то учет полиса будет производится только после его оформления. Полис в таком случае может не иметь номера вообще, или будет заполняться вручную, или будет определен из списка свободных номеров полисов.
