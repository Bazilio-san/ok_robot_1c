Режим отладки печати при использовании справочника Печатные Формы

Включает вывод дополнительной информации и отработки дополнительных отладочных действий при печати форм из справочника Печатные Формы.

  • вывод сообщений об ошибках при выполнении кода заполнения параметров
  • все места подстановки параметров в макете, которым в коде обработки не присваиваются значения, будут заполнены строкой ###########. Это позволяет визуально отследить проблемные места в шаблоне и коде.

Настрока управляет значением параметра сеанса уб_отладка_Печати.

Печать макета ТЕСТ и запуск уб_ПФ.ПечатьТЕСТ (для справочника "ПФ")

Эта настройка позволяет осуществить отладку печати при разработке печатных форм для справочника Печатные Формы.

Она управляет возможностью при печати, выводить на печать вместо макета из справочника общий макет с именем "ТЕСТ", а вместо кода
из справочника запускать код процедуры уб_ПФ.ПечатьТЕСТ.

Предполагается, что в тело процедуры уб_ПФ.ПечатьТЕСТ копируется код из справочника.
Это позволяет поставить в нем точки останова и произвести отладку в Конфигураторе.

Настрока управляет значением параметра сеанса уб_отладка_ПечататьТЕСТМакет.
