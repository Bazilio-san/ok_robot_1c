Настройка параметров учета

В форме "Настройка параметров учета" устанавливаются параметры аналитического учета - общие для всех организаций информационной базы.

Закладка "Аналитический учет МПЗ"

На этой закладке устанавливаются следующие параметры:

  • признаки ведения партионного учета (флаг "Вести партионный учет"), складского учета (флаг "Вести складской учет") и суммового учета по складам (флаг "Вести суммовой учет по складам"), раздельно для бухгалтерского учета и налогового учета;
  • для организаций, оценивающих товары в розничной торговле по продажным ценам (соответствующий признак устанавливается в учетной политике бухгалтерского учета) — признак использования оборотной аналитики по номенклатуре (флаг "Использовать оборотную аналитику по номенклатуре") и признак учета товаров в разрезе ставок НДС (флаг "Учитывать товары в разрезе ставок НДС");
  • признак необходимости учета возвратной тары (флаг "Использовать возвратную тару").

Примечание

При установке флага "Вести партионный учет" в плане счетов на счетах бухгалтерского и налогового учета, предусматривающих аналитический учет по субконто "Номенклатура" (10 "Материалы", 41 "Товары", 43 "Готовая продукция" и т.д.), автоматически будет установлено субконто "Партии". При снятии указанного флага субконто "Партии" будет автоматически убрано с этих счетов. При этом вся информация о партиях в проводках будет потеряна.

При установке флага "Вести складской учет" в плане счетов на счетах бухгалтерского и налогового учета, предусматривающих аналитический учет по субконто "Номенклатура" (10 "Материалы", 41 "Товары", 43 "Готовая продукция" и т.д.), автоматически будет установлено субконто "Склады". При снятии указанного флага субконто "Склады" будет автоматически убрано с этих счетов. При этом вся информация о складах в проводках будет потеряна.

Закладка "Аналитический учет расчетов с контрагентами"

На этой закладке устанавливается признак детализации расчетов с контрагентами до документов (флаг "Вести расчеты по документам").

Примечание

При установке флага "Вести расчеты по документам" в плане счетов на счетах расчетов с контрагентами (60 "Расчеты с поставщиками и подрядчиками", 62 "Расчеты с покупателями и заказчиками", субсчета по прочим расчетам счета 76 "Расчеты с разными дебиторами и кредиторами") автоматически будет установлено дополнительное субконто "Документы расчетов с контрагентами". При снятии указанного флага субконто "Документы расчетов с контрагентами" будет автоматически убрано с этих счетов. Вся информация о документах расчетов с контрагентами в проводках при этом будет потеряна.

По счетам расчетов в условных единицах субконто "Документы расчетов с контрагентами" присутствует постоянно и не может быть изменено из настройки аналитического учета.

 

Закладка «Обмен данными»

На этой закладке задаются параметры для автоматического обмена данными при работе с распределенными информационными базами.
