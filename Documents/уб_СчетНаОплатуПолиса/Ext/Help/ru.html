Документ «Счет на оплату полиса»

            Счета на оплату полиса оформляются документом «Счет на оплату полиса». Документ имеет таблицу с колонками: «Дата» — дата создания документа, «Номер» — номер оплачиваемого полиса, «Подразделение» — название подразделения, «Страхователь» — имя страхователя, «СК» — страховая компания, «Сума» — сумма оплаты, «Валюта» — валюта оплаты, «Автор» — автор документа. Документ не производит никаких движений в регистрах. Он предъявляется страхователю для платы.

            Список документов можно сортировать по содержимому в колонках «Дата» и «Номер».

            Новый документ создается с помощью диалога — формы элемента. Данная форма содержит реквизиты, имеющие отношение к данному документу и табличную часть о премии по полису.

            В реквизите «Страховая компания» есть раскрывающийся список с названиями всех страховых компаний. Из списка следует выбрать страховую компанию. Чтобы выбрать страхователя, необходимо в реквизите «Страхователь» нажать на троеточиеи выбрать из справочника «Контрагенты». Если страхователь сам платит премию по полису, то следует установить флажок «Он же плательщик». Банковский счет выбирается в реквизите «Банковский счет». Чтобы получить список банковских счетов, доступных для оформления в данном подразделении, следует нажать на значок «Троеточие»справа от реквизита. Из полученного списка банковских счетов нужно выбрать один счет двойным щелчком левой кнопкой мыши. Реквизит валюта является реквизитом справочника «Валюты». Реквизит «Ответственный» является реквизитом справочника «Пользователи».  В реквизите «Подразделение» необходимо указать подразделение, в котором оформляется счет на оплату полиса.

            Счет на оплату содержит табличную часть, куда вносятся все премии для данной страховой компании от одного страхователя. В колонке «Наименование» нужно записать название счета. В колонке «Ед.» следует занести единицу измерения, например, штука. В колонку «Количество» следует занести количество полисов. В колонке «Цена» содержится цена за одну единицу измерения. В колонке «Сумма» следует внести всю сумму премии за то количество полисов, которое указано в колонке «Количество».
