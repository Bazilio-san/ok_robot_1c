Регистр сведений "Свободные Номера Полисов"

Измерения:

СК, Поставщик, НомерПолиса - Заполняются при поступлении номера

Ресурсы

ВидНумерации, ГодПолиса - заполняется при поступлении номера и далее не меняются

НомерИспользован - при поступлении номера - ЛОЖЬ. При проведении страхового полиса устанавливается в ИСТИНА. Служит для использования в выборках для быстрого получения информации.

Установка флага сопровождает операцию ОформлениеПолиса. Эта операция не возможна, если номер до этого был Использован (оформлен), Зарезервирован или Заблокирован (предварительно нужно будет снять проведение документов, которыми использовался, резервировался или блокировался номер).

НомерЗаблокирован - при поступлении номера - ЛОЖЬ. Может быть установлено либо через форму "Выдача номеров", либо через форму документа "Движения номеров полисов". Используется в случае, если необходимо запретить оформление полиса с этим номером. Заблокированный номер не будет отображаться в списке номеров, который выводится в документе Страховой Полис при подстановке номера полиса.

Установка флага сопровождает операцию "БлокировкаНомера". Свойство нельзя установить, если номер ранее был Использован (оформлен) или Зарезервирован (предварительно нужно будет снять проведение документа Страховой Полис (а так же снять в нем флаг "Резервировать номер полиса"), которым оформлялся/резервировался данный номер).  

НомерЗарезервирован - при поступлении номера - ЛОЖЬ.

Может быть установлено только документом "Страховой Полис". Этот признак - альтернатива признаку "Использован". Используется в случае, когда полис еще не проеден, но нужно исключить возможность выбора этого номера для другого полиса.

Установка флага сопровождает операцию РезервированиеНомера, которая происходит при записи непроведенного документа Страховой Полис, если отмечен чекбокс "Резервировать номер полиса".

Эта операция не возможна, если номер до этого был Использован другим документом или Заблокирован (предварительно нужно будет снять проведение документов, которыми оформлялся или блокировался номер).

НомерВыданАгенту - ссылка на Агента. Может быть установлено (или снято) либо через форму "Выдача номеров", либо через форму документа "Движения номеров полисов". По этому признаку определяется, кому выдан Номер. По этому признаку фильтруется список Номеров при подстановке номера в Страховом Полисе. При оформлении полиса этот признак сохраняется (номер остается закрепленным за агентом, но уже как Использованный) 

Реквизиты

КодОперации - прописывается при каждом движении.

ПолучениеНомера - при поступлении Номера

ВыдачаНомера - при смене значения поля НомерВыданАгенту на НЕ пустое значение

ОсвобождениеНомера - при смене значения поля НомерВыданАгенту на пустое значение

БлокировкаНомера - при установке/снятии флага НомерЗаблокирован

РезервированиеНомера - при установке/снятии флага НомерЗарезервирован

ОформлениеПолиса - при проведении страхового полиса
