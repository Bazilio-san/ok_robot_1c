Отчет Маниторинг остатков БСО

Предназачен для вывода остатков БСО по видам БСО для текущего пользователя.

Может выводить остатки как по всем видам БСО, так и по отслеживаемым видам БСО. Являеться ли вид БСО отслеживаемым, определяеться с помощью установки признака "Отслеживать остатки" в форме элемента вида БСО.

При выводе остатка используются три цвета отображения количества остатков:

 Красный - Остатков нет.

 Желтый - Остаток есть, но он меньше количества границы придупреждения о нехватке осатков. Граница предупреждения для каждого вида БСО индивидуальна и устанавливаеться в форме элемента вида БСО.

 Зеленый - Остаток есть и его колличество больше границы предупреждения о нехватке остатков.
