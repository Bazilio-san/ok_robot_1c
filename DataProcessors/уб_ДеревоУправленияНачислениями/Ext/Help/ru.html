Предназначена для добавления и управления существующими записами регистра сведений "Начисления сотрудников".

Данные этого регистра используются при расчете заработной платы

 

Для обновления списка используется кнопка "Обновить"

Для добавления записи используется кнопка "Добавить"

Добавить запись уже присутствующего в списке физического лица можно при при двойном щелчке по нему.

Изменить запись можно двойным щелчком по ней.

Для отмены записи необходимо зайти в режим изменения и отключить флаг "Действует"
